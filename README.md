# BookSmart — Online Bookstore

**Solo project** · Web Application Development module, University of Technology, Mauritius (2025)

BookSmart is an e-commerce bookstore website. Customers browse, search and buy books; admins manage the catalogue, users and orders.

## Features
- Sign-up and role-based login (Admin and Customer)
- Browse and search books by category, book details page
- Shopping cart, checkout, payment page and order history
- Admin console: manage books, admins, users, orders, payments and reports

## Tech
C# · ASP.NET Web Forms · SQL Server · HTML/CSS

## Run it locally
1. Open `BookSmart.sln` in Visual Studio.
2. Create a SQL Server database called `BookSmartDB`.
3. In `BookSmart/Web.config`, replace `YOUR_DB_USER` and `YOUR_DB_PASSWORD` in `myConnectionString`.
4. Restore NuGet packages and run.
